# 时间同步异常处置手册

## 告警与影响

当节点系统时间偏差超过阈值、NTP 同步状态失效或认证系统出现时间戳校验失败时触发告警。时间漂移会导致日志顺序混乱、分布式任务错过调度窗口、令牌校验失败以及证书有效期判断异常。

## 排查步骤

采集异常节点和标准时间源的当前时间，确认偏差大小、持续时间和影响范围。检查 NTP 或 chrony 服务状态、上游时间服务器连通性和最近同步日志。比较虚拟机宿主机、容器节点与应用进程时间，识别是单节点问题还是整个网络时钟源异常。

## 常见原因与处理

时间同步服务未运行时，恢复服务并重新同步时间。上游 NTP 服务器不可达时，修复 DNS、网络策略或切换到可用的备用时间源。虚拟化环境时钟漂移时，检查宿主机时间同步配置并避免多个时间服务同时校时。对于偏差过大的节点，应先评估对数据库、消息和认证请求的影响，再采用受控方式校正，避免时间回拨造成额外问题。

## 验证与预防

确认节点偏差回到阈值内、同步服务稳定，且认证失败和调度异常恢复。配置多个可信时间源，持续监控时间偏差与同步状态，并在节点初始化和发布检查中校验时间服务。
