# TLS 证书即将过期或已过期处置手册

## 告警与影响

当证书剩余有效期低于 30 天，或网关、服务端出现 `certificate has expired`、`x509: certificate signed by unknown authority` 等错误时触发告警。证书过期会导致浏览器和客户端拒绝 TLS 握手，API 调用失败，并可能引发外部依赖回调中断。

## 排查步骤

使用证书监控确认告警域名、证书序列号和到期时间。通过 `openssl s_client` 或入口网关的证书详情核对线上实际提供的证书，避免只检查本地文件。检查证书链是否完整，确认续签后的证书是否已同步至负载均衡、网关和全部实例。

## 常见原因与处理

自动续签任务失败时，检查域名验证、DNS 解析和续签账号权限；修复后先在非生产环境验证签发结果。证书已经续签但线上仍为旧版本时，重新加载网关配置并滚动更新使用该证书的实例。若中间证书缺失，部署完整证书链而不是只替换叶子证书。对于即将到期的证书，应优先完成续签和灰度替换，再安排历史证书清理。

## 验证与预防

从外部网络验证握手成功、证书链完整且到期时间符合预期，同时观察 TLS 握手错误和 API 成功率恢复。为全部域名设置 30 天、14 天和 7 天的分级到期告警，并将证书续签、分发和加载状态纳入发布检查项。
