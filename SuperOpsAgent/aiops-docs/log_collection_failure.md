# 日志采集失败处置手册

## 告警与影响

当日志采集代理离线、采集延迟持续升高或日志平台出现数据断档时触发告警。故障期间无法及时检索应用日志，审计和告警规则也会因缺少事件而失效。

## 排查步骤

确认采集代理进程、配置版本和到日志平台的网络连通性。检查代理自身日志，区分认证失败、缓冲区满、文件路径错误、磁盘空间不足和目标端不可用。对比应用实际产生的日志文件与平台中的最新时间戳，确定是采集端未读取、传输失败还是平台索引延迟。

## 处理与验证

代理异常退出时恢复进程并检查资源限制；配置变更后路径不匹配时修正采集规则并灰度发布。缓冲区或本地磁盘不足时释放空间、提高合理缓冲并处理日志突增原因。日志平台不可用时先恢复目标端并确保代理可重试，避免直接丢弃尚未发送的数据。验证关键服务日志连续进入平台、采集延迟恢复，并监控代理存活、缓冲积压、磁盘使用率和日志断档。
