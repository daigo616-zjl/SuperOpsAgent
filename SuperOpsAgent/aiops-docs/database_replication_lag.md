# 数据库复制延迟处置手册

## 告警与影响

当主从复制延迟持续超过业务阈值、从库回放停滞或只读查询返回明显旧数据时触发告警。读写分离场景下会出现读到旧状态、报表延迟和故障切换风险增大等问题。

## 排查步骤

确认复制链路的延迟、回放位置和从库错误日志，区分网络传输慢、从库回放慢与复制中断。检查主库写入峰值、长事务和大批量变更，确认是否产生了大量待回放日志。查看从库 CPU、磁盘 I/O、可用空间和慢查询，评估是否因资源瓶颈导致回放无法跟上。

## 处理与验证

网络异常时恢复主从连通性；从库资源不足时扩容或将只读流量迁移到健康副本。对于大事务或批处理造成的积压，等待回放并调整后续任务的批次和执行窗口。复制中断时根据错误原因修复账号、日志或数据一致性问题，再按既定流程恢复复制。验证延迟回落、回放持续推进且只读数据满足业务时效要求，并对复制延迟、回放错误和从库容量设置告警。
