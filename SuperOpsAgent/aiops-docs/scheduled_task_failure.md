# 定时任务失败处置手册

## 告警与影响

当定时任务连续失败、超过预期执行窗口未完成或执行耗时显著增长时触发告警。数据同步、对账、归档和清理等依赖任务会延迟，重复补偿还可能造成数据重复或下游压力上升。

## 排查步骤

检查任务调度器的触发记录、任务实例日志、执行参数和最近一次成功时间。确认任务是否真正未被调度，还是已触发但执行失败或长时间运行。核对运行实例、任务锁和幂等记录，排查是否存在多实例抢占、锁未释放或前一轮任务尚未结束。

## 常见原因与处理

业务逻辑异常或依赖服务不可用时，先修复依赖或错误数据，再在确认幂等性后手动补跑。执行时间超过调度间隔时，优化批处理范围或调整调度周期，避免任务重叠。任务锁残留时，在确认没有活动执行实例后释放锁；不要直接并发重跑。凭据过期、配置变更和磁盘空间不足也会导致任务失败，应恢复配置、权限或可用容量。

## 验证与预防

确认补跑任务成功、目标数据完整且没有重复写入，并观察下一周期可正常自动触发。为任务记录执行时长、成功率、积压量和最后成功时间；对关键任务配置失败告警、幂等保护和可审计的补跑流程。
